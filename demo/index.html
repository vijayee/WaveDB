WaveDB

A hierarchical, expressive, JSON-first database

Inspired by MUMPS and ForestDB, WaveDB stores objects instead of rows, speaks GraphQL, thinks in graphs, and searches by vector similarity — all in one embeddable engine.

What is WaveDB?

WaveDB was built to make databases more accessible. The core is a hierarchical B+Trie key-value store that lets you put, get, and traverse rich JSON objects without normalization or SQL joins.

  • Hierarchical keys
    Paths like users/alice/profile land exactly where you expect.
  • JSON objects
    Store arrays, maps, and scalars together — no shredding.
  • Schema layers
    GraphQL, Graph, and Vector layers share one storage engine.
  • Embeddable
    Bindings for Node.js, Python, and Dart.

Where does WaveDB fit? SQL vs NoSQL

Traditional SQL databases enforce rigid schemas, fixed tables, and strict relationships. NoSQL databases trade that rigidity for flexibility: document stores, key-value stores, wide-column stores, and graph databases each optimize for different shapes of data.

WaveDB is a NoSQL engine at heart — hierarchical keys, JSON objects, graph triples, and vector embeddings coexist without a fixed schema — while still giving you ACID durability and synchronous, embeddable access.

Inside WaveDB: Hierarchical B⁺Trie (HB⁺Trie)

A WaveDB key is a path made of identifiers, and each identifier is a sequence of fixed-size chunks. An HB⁺Trie is a tree of B⁺trees: each level searches one chunk, and the result points to the next B⁺tree (or to the final document).

Example path: users/alice/profile

flowchart TD
Root("Root HBTrie")
Level1("HBTrie users")
Level2("HBTrie users alice")
Doc("Document or Value")
Prod("HBTrie products")
ProdDoc("Document or Value")
Root -- "users" --> Level1
Level1 -- "alice" --> Level2
Level2 -- "profile" --> Doc
Root -- "products" --> Prod
Prod -- "item-42" --> ProdDoc
  • Path: a sequence of identifiers
  • Identifier: chunked string, e.g. users
  • HB⁺Trie node: one B⁺tree per identifier level
  • Leaf: document, scalar, or nested trie
